# vanderburg-editorial-theme

Editorial brand theme for the Stateless CMS — **deep teal · ivory · turquoise**, with
**Playfair Display + Montserrat**, sharp 2px corners and generous whitespace. Reconstructed
from the Van der Burg brand handoff.

- `theme.css` — full design mapped onto the CMS classes/tokens (ivory background, teal CTAs,
  turquoise accents, editorial serif headings, uppercase tracked labels)
- `theme.js` — shared chrome (header/footer/WhatsApp) + baker library
- `assets/` — brand logos (teal for light, ivory for dark) + monogram

Apply by setting `"themeBase": "https://rjvdburg.github.io/vanderburg-editorial-theme/"` in a
site's `cms.config.json`, then re-bake. Palette: #0D3B3A / #5F9E9A / #F5EFE9 / #D7C8BE / #1F1F1F.
